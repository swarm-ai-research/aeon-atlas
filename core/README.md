# Core Decentralized Protocols & Primitives

This directory contains foundational protocols and primitives that underpin AUS-Monorepo systems.

## What's Here

Core components form the foundation for all higher-level systems:

- **Consensus algorithms** — Byzantine fault-tolerant decision-making
- **Primitive protocols** — Building blocks for distributed systems
- **State machines** — Deterministic execution frameworks
- **Message protocols** — Inter-system communication standards
- **Synchronization** — Clock sync, ordering, causality tracking

## Design Principles

All core protocols must:
1. **Be formally specified** — Include pseudocode or mathematical notation
2. **Justify design choices** — Explain trade-offs and alternatives
3. **Document assumptions** — Be explicit about threat models
4. **Provide test vectors** — Include examples for verification
5. **Enable verification** — Make implementation checking feasible
