# Administrative Procedures

Step-by-step processes for common federal administrative functions.

## Procedure Categories

- **Applications & Approvals** — Licensing, permits, grants
- **Compliance & Reporting** — Audit, compliance, submission procedures
- **Personnel** — Hiring, discipline, retirement
- **Financial** — Budgeting, procurement, payments
- **Records** — Management, access, retention
- **Incident Response** — Crisis, emergency, violation handling

## Contributing

To add a procedure:
1. Document the actual current process
2. Include all steps and decision points
3. Cite responsible parties
4. Include service level agreements
5. Submit PR with [PROCEDURE] label
