# ISS-005 — scheduler quiet window (~65h), missed heartbeat + weekly atlas slots

## Symptom

As of this 2026-09-01 15:33 UTC heartbeat run, `memory/cron-state.json` shows:
- **heartbeat** — `last_success: 2026-08-29T21:56:01Z`, `last_status: success`, `last_dispatch: 2026-08-29T21:54:31Z`, `consecutive_failures: 0`, `success_rate: 0.88` (219/248). Self-check: last_success is **~65.6h ago**, past the 36h P0 self-check threshold → flagged.
- **atlas** — frozen at `last_success: 2026-08-23T04:41:06Z` (Sunday 04:00 weekly). The 2026-08-30 04:00 slot did not dispatch.
- **atlas-layers** — frozen at `last_success: 2026-08-23T05:08:38Z` (Sunday 05:00 weekly). The 2026-08-30 05:00 slot did not dispatch.
- **atlas-improve** — dispatched cleanly `2026-09-01T06:19:12Z` → `last_success 2026-09-01T06:20:34Z` (log written).

## Impact

- **~65h with no fleet health checks** between the clean 08-29 20:00 run (last_success 21:56Z, late) and this catch-up run — the longest monitoring gap on record (cf. ISS-004 ~24h).
- `docs/status.md` went stale (Updated 2026-08-29 21:55 UTC) for ~2.7 days, well past the ~8h staleness banner.
- **Two weekly atlas runs skipped** (atlas + atlas-layers, 2026-08-30 Sunday). No atlas.json snapshot or atlas-layers PR was produced for that week; the next scheduled attempt is Sunday 2026-09-06.

## Distinction from ISS-004

ISS-004 (2026-08-06) was a *hung run*: `last_status: dispatched` that never reported back. **This is different** — `last_status` is `success` and `last_dispatch` never advanced past 08-29 21:54, meaning the scheduled workflow simply **did not fire** heartbeat for the missed slots. Not a crash mid-run; a missed dispatch. That atlas-improve fired on time at 09-01 06:00 rules out a total scheduler outage — the misses are slot-specific, not window-wide.

## Lineage / why filed now (not deduped)

The 08-27/08-28/08-29 logs each noted apparent missed heartbeat slots but stayed **under** the 36h self-check threshold, so no P0 fired and no issue was filed ("watch for >36h staleness next slot"). That checkpoint has now been crossed (~65h), and the miss extended to the weekly atlas cohort — meeting the ISS-004 escalation criterion ("if another slot hangs/misses within the next few cycles, escalate"). Filed at **high** severity accordingly.
