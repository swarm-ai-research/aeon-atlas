## Recommended durable fix (carried forward from ISS-005→009 — still operator-action-required)

The repeated lineage proves the per-slot self-heal loop is a reprieve, not a fix:
- **Redundant offset cron** — a second `schedule:` a few minutes offset from each slot so a single dropped cron delivery doesn't dark the slot.
- **External dispatch ping** — an off-GitHub scheduler (cron-job.org / external worker) calling `workflow_dispatch` as a backstop when native `schedule:` drops (also re-triggers hung runs).

`skill-repair` is still `enabled: false`, so no automated code fix will land — the backstop must be shipped by the operator.
