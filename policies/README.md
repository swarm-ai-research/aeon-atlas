# Policies & Legislation

This directory contains Australian government policies, legislation, and regulatory frameworks.

## Directory Structure

Organized by policy area:
- `policy-name.md` — Full policy text or summary
- `related-legislation.md` — Linked laws and acts

## Policy Template

```markdown
# Policy Name

**Enacted**: YYYY-MM-DD
**Last Updated**: YYYY-MM-DD
**Responsible Department**: [[Department Name]]
**Policy Status**: Active | Draft | Archived

## Purpose
Clear statement of the policy's goals and rationale.

## Scope
Who, what, and where the policy applies.

## Key Principles
- Principle 1
- Principle 2

## Provisions
Detailed policy requirements, organized by section.

### Section 1: [Title]
Description and requirements.

### Section 2: [Title]
Description and requirements.

## Implementation
How the policy is implemented and enforced.

## Exemptions & Exceptions
Cases where the policy does not apply.

## Compliance & Reporting
Requirements for compliance monitoring and reporting.

## Related Legislation
- [[Act Name (Year)]]
- [[Regulation Name]]

## Review & Amendment History
| Date | Change | Reason |
|------|--------|--------|
| YYYY-MM-DD | Amendment description | Reason |

## Resources & Guidance
- [[Implementation Guide]]
- [[FAQs]]
- [[Contact Information]]
```

## Contributing

To add a new policy:
1. Create descriptive filename: `policy-short-name.md`
2. Use the template above
3. Include official status and effective dates
4. Link to related documents
5. Submit PR with [POLICY] label
