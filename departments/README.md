# Federal Departments & Agencies

This directory contains documentation for Australian federal government departments and agencies.

## Directory Structure

Each department has its own file:
- `department-name.md` — Overview, structure, responsibilities
- Related documents linked within

## Department Template

When adding a department, use this structure:

```markdown
# Department Name

**Established**: YYYY-MM-DD
**Last Updated**: YYYY-MM-DD
**Responsible Minister**: [Name]

## Overview
Brief description of the department's purpose and mandate.

## Organizational Structure
- Secretary/Head of Department
  - Division 1
    - Section A
    - Section B
  - Division 2

## Key Responsibilities
- Responsibility 1
- Responsibility 2
- Responsibility 3

## Agencies & Offices
- [[Agency Name]]
- [[Related Office]]

## Contact Information
- **Headquarters**: [Address]
- **Phone**: [Number]
- **Email**: [Contact]
- **Website**: [URL]

## Key Legislation
- Act 1 (Year)
- Act 2 (Year)

## Current Priorities
- Priority 1
- Priority 2

## Budget & Resources
- Annual budget: $X million (FY2026)
- Staff: Approx. [number]

## Related Documents
- [[policy-document]]
- [[procedure-document]]
```

## Contributing

To add a new department:
1. Create `department-name.md` following the template
2. Include current official information
3. Link to related documents
4. Submit a pull request with [DEPARTMENT] label
